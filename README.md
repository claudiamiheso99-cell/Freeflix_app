# FreeFlix

A Flutter starter for a free, rights-compliant movie streaming app.

## Run
1. Install Flutter and Android Studio.
2. Extract this project.
3. Run `flutter pub get`.
4. Connect an Android phone/emulator.
5. Run `flutter run`.

## Important
The upload screen is a prototype: it selects a local video but does not yet upload it to a cloud server. A production app should use authenticated cloud storage, a backend database, video transcoding/HLS, moderation, copyright/takedown controls, and secure streaming URLs.

Only distribute movies you own, licensed movies, or public-domain content.
